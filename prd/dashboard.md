# 仪表盘 PRD

## 1. 功能概述

仪表盘是管理端首页，集中展示系统核心运营数据和快捷入口，帮助管理员快速掌握全局状态。

## 2. 页面布局

```
+---------------------------------------------------+
| 统计卡片区（4列）                                |
| 总用户 | 总订单 | 总销售额 | 待处理 |
+---------------------------------------------------+
| ECharts 图表区                     | 快捷操作   |
| 折线图（订单趋势） | 柱状图（销售TOP）| - 新增用户 |
| 环形图（用户分布） | 面积图（GMV）    | - 查看订单 |
|                                     | - 商品管理 |
+---------------------------------------------------+
| 最近订单表格                                     |
| 订单号 | 用户 | 金额 | 状态 | 时间 |
+---------------------------------------------------+
```

## 3. 统计卡片

| 卡片 | 数据源 | 趋势展示 |
|------|--------|----------|
| 总用户 | users.length | 本周新增 N ↑ |
| 总订单 | orders.length | 今日新增 N ↑ |
| 总销售额 | sum(orders.amount) | 本周 ↑12% |
| 待处理 | orders.filter(status=pending) | 今日 +5 |

## 4. ECharts 图表

### 4.1 订单趋势折线图
- X轴：最近7天日期
- Y轴：订单数量
- 双折线：下单数 vs 完成数
- 统一配色：#2563EB（下单）/ #10B981（完成）

### 4.2 销售TOP10 柱状图
- X轴：商品名称（横向柱状图）
- Y轴：销售额
- 取销售额前10的商品

### 4.3 用户角色分布环形图
- 数据：管理员 / VIP / 普通用户占比
- 配色：#2563EB / #F59E0B / #E5E7EB

### 4.4 GMV 趋势面积图
- X轴：最近30天
- Y轴：日 GMV
- 面积填充半透明蓝色

## 5. 快捷操作

| 按钮 | 行为 |
|------|------|
| 新增用户 | 跳转用户管理并打开新增弹窗 |
| 查看订单 | 跳转订单管理 |
| 商品管理 | 跳转商品管理 |
| 数据看板 | 跳转运营端数据看板 |

## 6. 最近订单

- 展示最近 5 笔订单
- 列：订单号 / 用户 / 金额 / 状态 / 时间
- 点击行 → 跳转订单管理详情

## 7. 响应式

- 统计卡片：桌面 4 列 → 平板 2 列 → 手机 1 列
- 图表区：桌面 2×2 网格 → 平板/手机 1 列
- 快捷操作：移动到图表区下方
