# 商品列表 PRD

## 1. 功能概述

商品列表页是用户端商城的核心浏览页面，展示系统所有上架商品，支持多条件筛选和排序。

## 2. 页面布局

```
+-------------------------------------------------+
| 左侧筛选区(240px) | 商品网格区域               |
| - 分类树          | +--------+ +--------+      |
| - 价格区间        | | 商品卡 | | 商品卡 |      |
| - 品牌筛选        | +--------+ +--------+      |
|                   | +--------+ +--------+      |
| 排序: 综合/销量/价格↑↓ |  共 128 件商品         |
+-------------------------------------------------+
```

## 3. 核心功能

### 3.1 商品展示
- 商品卡片：图片 + 名称 + 价格 + 销量 + 评分
- 网格布局，自适应列数（最小 200px）
- 图片懒加载，可视区域优先渲染

### 3.2 筛选
- 分类筛选：左侧分类树，支持多级展开
- 价格区间：最小/最大价格输入框
- 品牌筛选：多选 checkbox
- 筛选条件实时生效（防抖 300ms）

### 3.3 排序
- 综合（默认）
- 销量从高到低
- 价格从低到高
- 价格从高到低
- 评分从高到低

### 3.4 分页
- 无限滚动加载（移动端）
- 传统分页（桌面端）：每页 24 件

## 4. 商品卡片设计

```
+-------------------+
|                   |
|   商品图片 1:1    |
|                   |
+-------------------+
| 商品名称（2行截断）|
| ¥299              |
| 已售 1.2k  ★4.8  |
+-------------------+
```

## 5. 交互细节

- 鼠标悬浮商品卡片：轻微上浮 + 阴影加深
- 点击商品卡片：跳转商品详情页
- 空筛选结果：显示空状态插画 + 「清除筛选」按钮
- 加载中：骨架屏占位

## 6. 接口

```js
MockAPI.getProducts({
  page: 1,
  pageSize: 24,
  category: "智能穿戴",
  brand: ["苹果", "华为"],
  minPrice: 100,
  maxPrice: 5000,
  sort: "sales_desc"
})
```
