# 用户管理 PRD

## 1. 功能概述

用户管理模块是后台管理系统的核心功能之一，用于管理系统注册用户的信息、角色和状态。

## 2. 页面布局

```
+-----------------------------------------------+
| 搜索框 | 筛选下拉 | 新增按钮 |
+-----------------------------------------------+
| 用户名 | 手机号 | 角色 | 状态 | 注册时间 | 操作 |
|        |        |      |      |          | 查看/编辑 |
+-----------------------------------------------+
| 分页：共 128 条  < 1 2 3 >  跳页   每页 10 条 |
+-----------------------------------------------+
```

## 3. 核心功能

### 3.1 用户列表
- 展示用户基本信息：头像、用户名、手机号、邮箱、角色、状态、注册时间
- 支持按用户名/手机号/邮箱模糊搜索
- 支持按角色（管理员/VIP/普通用户）筛选
- 支持按状态（启用/禁用）筛选
- 支持分页，可切换每页条数（10/20/50/100）

### 3.2 新增用户
- 点击「新增用户」按钮打开表单弹窗
- 必填字段：用户名、手机号、邮箱
- 选填字段：角色（默认普通用户）、状态（默认启用）
- 手机号/邮箱唯一性校验，重复时提示错误

### 3.3 查看用户
- 点击「查看」打开详情弹窗
- 展示用户完整信息，包括头像、基本信息、角色、状态
- 关闭弹窗后回到列表

### 3.4 编辑用户
- 点击「编辑」打开编辑弹窗，回填用户信息
- 修改后点击确认保存

### 3.5 启用/禁用用户
- 列表操作列提供启用/禁用切换
- 禁用用户后该用户无法登录系统

## 4. 数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 用户ID（自增） |
| username | string | 用户名 |
| phone | string | 手机号（唯一） |
| email | string | 邮箱（唯一） |
| role | string | 角色：管理员/VIP/普通用户 |
| status | string | 状态：active/disabled |
| createdAt | string | 注册时间 |

## 5. 交互规范

- 表单弹窗：遮罩层不可关闭，ESC 不可关闭（防止误触丢失已填内容）
- 查看/确认类弹窗：可点击遮罩关闭，ESC 可关闭
- 所有输入框右侧显示字符计数器
- 搜索框支持防抖（300ms 自动搜索）

## 6. 接口列表

| 接口 | 方法 | 说明 |
|------|------|------|
| MockAPI.getUsers(params) | GET | 分页查询用户列表 |
| MockAPI.addUser(user) | POST | 新增用户 |
| MockAPI.getUserById(id) | GET | 查询单个用户详情 |
| MockAPI.updateUser(id, data) | PUT | 编辑用户 |
| MockAPI.toggleUserStatus(id) | PATCH | 启用/禁用用户 |
