# 新增用户功能 PRD

## 1. 需求背景

管理员需要在后台手动录入用户信息，用于系统初始化或特殊场景下的用户创建。

## 2. 功能入口

- 用户管理页面右上角「新增用户」按钮
- 点击后弹出表单弹窗

## 3. 表单字段

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| 用户名 | text | ✅ | 2-20字符，支持中英文数字 |
| 手机号 | text | ✅ | 11位手机号格式，系统内唯一 |
| 邮箱 | text | ✅ | 邮箱格式，系统内唯一 |
| 角色 | select | ❌ | 管理员/VIP/普通用户（默认普通用户）|
| 状态 | select | ❌ | 启用/禁用（默认启用）|

## 4. 交互流程

1. 点击「新增用户」→ 弹窗打开
2. 填写表单内容，输入框右侧实时显示字符计数器
3. 点击「确认」→
   - 前端校验通过 → 调用 MockAPI.addUser → 成功 toast 提示 → 刷新列表 → 关闭弹窗
   - 前端校验失败 → 在对应字段下方显示错误提示
   - 接口返回 409（手机号/邮箱重复）→ 提示「该手机号/邮箱已被注册」
4. 点击「取消」或「×」→ 关闭弹窗

## 5. 弹窗规范

- **表单弹窗**：遮罩层点击不关闭，ESC 不响应
- 底部按钮不加图标，纯文字
- 标题前不加图标
- 头部紧凑高度：14px 20px
- 底部紧凑高度：12px 20px

## 6. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 用户名为空 | 提示「请输入用户名」 |
| 用户名过短 | 提示「用户名至少2个字符」 |
| 手机号格式错误 | 提示「请输入正确的手机号」 |
| 手机号已存在 | 提示「该手机号已被注册」 |
| 邮箱格式错误 | 提示「请输入正确的邮箱」 |
| 邮箱已存在 | 提示「该邮箱已被注册」 |
